# Kalumba Plumbing demo

Open `index.html` in a browser. No installation or build step is needed.

Built in the same HTML, CSS and JavaScript structure and editorial navy style as the supplied FJ Automotive demo. Includes responsive navigation, service accordions, scroll animations, a WhatsApp enquiry form, call links, a service-area map and a local guide with prepared answers.

The form prepares a message for 079 956 5342. Visitors review and send it in WhatsApp; the website does not submit or store enquiries. Visits require confirmation from the business. No booking backend or live AI service is connected.

Business details and services follow the supplied Facebook screenshot. The map shows Klerksdorp, not a verified premises address. Prices are quoted individually. Registration statements are attributed to the supplied business profile.

Illustrative bathroom photography from Unsplash (not photographs of Kalumba projects):

Google Fonts and the Google Maps embed need internet access; local images and the main website work without a server.

The hero includes a local plumbing video with a matching poster, blue overlay and pause/play control. It respects reduced-motion and data-saver preferences and pauses offscreen. Video source and usage details are in `assets/VIDEO-CREDIT.md`.
